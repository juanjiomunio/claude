## OmniRoute

Router de IA unificado (API compatible con OpenAI, fallback automático entre proveedores).

```bash
./scripts/install-omniroute.sh --start
```

- Dashboard: http://localhost:20128
- API: `http://localhost:20128/v1` (API key en Dashboard → Endpoints)
- Requiere Node.js 22.22.2+ o 24+.
